## Montajcıya ne satıyoruz?

Onlara ürün satmıyoruz. **Satın alma kararının son metresinde görünürlük + nitelikli lead** satıyoruz.

1. **Featured profil** — istasyon / jeneratör / invertör sayfalarında öncelik (Basic / Featured / City).
2. **Calculator lead’leri** — kullanıcı daire/ev, kesinti süresi, yük ve bütçe girer; sonuç SES / hibrit / jeneratör montajı isterse firmaya düşer.
3. **Şehir önceliği** — “монтаж …” arayan veya calculator’da şehir seçen trafikte üst sıra.
4. **Aylık lead raporu** (City paketi) — kaç tıklama / form / telefon adayı.

### Neden teklifi kabul etsinler?

- Google Ads’te `монтаж сонячних панелей` CPC **~$0.66**, üst teklif **~$0.96**. 1000 arama ≈ **$660–960/ay** sadece o kelime.
- Bizim Featured **3 999 ₴/ay** (~$95–100) — Ads’ten ucuz, ve zaten satın alma niyeti taşıyan site trafiğinde.
- Bir SES / hibrit iş **80 000–400 000+ ₴**. Tek kapalı iş birkaç aylık paketi öder.
- Rakip SERP dağınık (OLX + firma siteleri); tarafsız “hangi sistem” sayfasında featured slot az ve değerli.

### Onların neyini öneriyoruz?

- Ürün sayfalarında: “Bu istasyon / invertör için montaj gerekir → **doğrulanmış firma**”.
- Calculator sonucunda: `station` (affiliate) **veya** `inverter+AKБ` / `generator` / `solar hybrid` → **montajcı CTA**.
- Şehir + uzmanlık (СЕС, інвертор, генератор, ОСББ).

## Calculator kararı

**Evet — ama SEO kelimesi için değil, dönüşüm hunisi için.**

- “калькулятор …” toplamı ~100/ay → tek başına SEO hedefi değil.
- “для квартири / для дому / інвертор для дому” **binlerce**/ay → calculator bu niyeti **ürün + montaj** sonucuna çevirir.
- Lead kalitesi: ham tıklamadan yüksek (senaryo doldurulmuş).

Kapsam (MVP): konut tipi → kesinti süresi → kritik yükler → dış mekân jeneratör mümkün mü → bütçe → güneş uzun vadeli mi → öneri + ürünler + montajcı formu.

## Öncelik sırası

1. Calculator canlı + lead mail/webhook (montajcı değeri somutlaşır).
2. Claim satış konuşması: “Ads’ten ucuz, senaryolu lead”.
3. Mid-tail içerik: для квартири, для дому, підключення інвертора, монтаж (şehir).
4. Affiliate linkleri güçlendir.
5. Lead-fee paketi (City üstü).
